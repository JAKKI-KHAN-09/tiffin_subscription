# Tiffin Management System - Backend

## Technology

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

## Features

- Customer management
- Monthly subscriptions
- Pause / resume
- Service-day calculation
- Pro-rated billing
- Dashboard statistics

## Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
