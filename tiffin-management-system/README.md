# Tiffin Management System

A full-stack application for managing tiffin subscriptions, customer records, billing, and pause/resume workflows.

## Project Structure

- frontend/
- backend/
- database/
- tests/
- docs/

## Quick Start

1. Install frontend dependencies in `frontend/`
2. Install backend dependencies in `backend/`
3. Start the backend via FastAPI
4. Start the frontend via Vite
